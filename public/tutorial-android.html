Como colocar o Android virtual do GhostPhone para rodar

Guia para instalar/atualizar o GhostLens, ativar a virtualização do PC e abrir o Android que roda Instagram e TikTok. Versão atual: 3.5.5.

⬇️ Baixar GhostLens 3.5.5 ✅ Verificar meu PC 🩺 Abrir diagnóstico 🖥️ Abrir GhostLens Studio

O que o Anthony precisa fazer agora

  1. Feche o GhostLens e o daemon. Se necessário, use o Gerenciador de Tarefas e finalize GhostLens.exe, pythonw.exe e python.exe.
  2. Instale a 3.5.5 por cima. Não precisa desinstalar. A licença e os perfis continuam salvos.
  3. Confira a virtualização. Gerenciador de Tarefas → Desempenho → CPU → Virtualização. Se estiver desabilitada, siga o passo 4.
  4. Ative a virtualização na BIOS. Reinicie, entre na BIOS/UEFI e ative Intel VT-x ou AMD-V/SVM Mode. Salve e reinicie.
  5. Ative a Plataforma do Hipervisor do Windows. Menu Iniciar → “Ativar ou desativar recursos do Windows” → marque Plataforma do Hipervisor do Windows → reinicie.
  6. Rode “Configurar Motor Android”. Menu Iniciar → GhostLens → Configurar Motor Android. Deixe a janela terminar.
  7. Abra o GhostPhone. GhostLens → GhostPhone • Personas → Abrir GhostPhone. O primeiro boot pode levar até 120s.
  8. Se falhar, envie o diagnóstico. Abra http://127.0.0.1:4444/api/android_diag e mande o resultado para o suporte.

Ativar a virtualização na BIOS

Intel Procure por Intel Virtualization Technology, VT-x ou Intel VMX e deixe Enabled.
AMD Procure por SVM Mode, Secure Virtual Machine ou AMD-V e deixe Enabled.

As teclas para entrar na BIOS/UEFI variam por fabricante: Del, F2, F10 ou Esc. Salve com F10.

AMD: procure por “SVM Mode”

Na AMD, a opção pode aparecer como SVM Mode, Secure Virtual Machine, AMD-V ou AMD Virtualization. Ela não fica com o nome “Virtualization” na maioria das placas.

FabricanteCaminho comum
ASUSF7 (Advanced Mode) → Advanced → CPU Configuration → SVM Mode
MSIAdvanced → OC → Advanced CPU Configuration → SVM Mode
GigabyteTweaker → Advanced CPU Settings → SVM Mode
ASRockAdvanced → CPU Configuration → SVM
DellF2 → Virtualization Support → Virtualization (AMD-V/SVM)
HPF10 → System Configuration → Virtualization Technology (AMD-V)
LenovoF1 → Security → Virtualization → AMD-V / Configuration → SVM
AcerF2 → Advanced → SVM Mode

Se a BIOS tiver busca, procure por SVM. Em algumas placas AMD ele fica em Advanced → AMD CBS → CPU Common Options → SVM ou em Overclocking → Advanced CPU Configuration.

Se não encontrar SVM em nenhum lugar: atualize a BIOS ou mande o modelo da placa-mãe/PC para o suporte. Em PCs muito antigos ou CPUs AMD sem SVM, a virtualização não existe.
Sem virtualização, o Android x86_64 não roda em velocidade usável. Não existe instalação que ligue essa opção dentro do Windows: é uma configuração do firmware do PC.

O PC é compatível?

  • ✓Windows x64 (Intel/AMD). Windows ARM64 não é compatível com a imagem x86_64.
  • ✓Windows 10 ou 11 64-bit.
  • ✓Virtualização ativada na BIOS/UEFI.
  • ✓Plataforma do Hipervisor do Windows ativada.
  • !8 GB de RAM ou mais e 10 GB livres em disco.
  • !Feche BlueStacks, LDPlayer, Android Studio ou outro emulador antes de abrir o GhostPhone.

Todos os PCs vão dar erro?

Não. Os erros de arm e platform-tools eram bugs de configuração nossos e foram corrigidos na 3.5.2/3.5.4.

  • ✓PC Windows x64 com virtualização ativada → deve funcionar.
  • !PC com virtualização desligada → precisa ativar na BIOS.
  • ×Windows ARM64 → não compatível com a imagem x86_64.
  • !Pouca RAM, disco cheio, antivírus agressivo ou outro emulador aberto → podem falhar.
Para vender com menos suporte, faça uma verificação de compatibilidade antes: x64, virtualização ativa e 8 GB+ de RAM.

  2. Ativar virtualização na BIOS.
  3. Ativar Hipervisor do Windows.
  4. Rodar Configurar Motor Android.
  5. Abrir o GhostPhone.
